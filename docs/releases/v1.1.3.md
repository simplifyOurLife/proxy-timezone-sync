# v1.1.3 · 代理出口与网页时区同步

根据目标网站探测请求的出口 IP 自动选择网页时区，支持手动指定、域名范围、补丁模式和 CDP 模式。

本版本保留目标 trace 返回的国家信息，地理接口全失败时，新加坡等已支持的单一时区地区仍可自动选择。工具栏显示开关状态，弹窗长诊断内容默认折叠。

## 安装

下载 `proxy-timezone-sync-1.1.3.zip` 并解压，在 `chrome://extensions/` 开启开发者模式，点击“加载已解压的扩展程序”。选择直接包含 manifest.json 的目录。

升级后重新加载扩展并刷新目标网页。默认只影响 chatgpt.com、openai.com 及其子域；其他网页需要加入作用范围。

## 文件

- `proxy-timezone-sync-1.1.3.zip`：扩展运行文件及安装、隐私、许可说明。
- `proxy-timezone-sync-1.1.3.crx`：配置固定签名私钥后才生成；普通 Windows／macOS Chrome 的商店外安装受限制。
- `SHA256SUMS.txt`：本次实际生成文件的 SHA-256 校验和。
- `package-files.json`：扩展包的白名单文件清单。

附件以本次 Release 实际提供的文件为准；未配置签名密钥时只提供 ZIP。原生宿主机是可选功能，请从本仓库源码的 native-host 目录取得。
